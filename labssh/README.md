## Контрольные вопросы:

1. Что такое командная строка?

Командная строка (CLI) - это текстовый интерфейс для взаимодействия с операционной системой, позволяющий управлять файлами, программами и настройками компьютера с помощью текстовых команд.

2. Перечислите основные команды управления файлами в командной строке.

ls (List) — выводит список файлов и директорий в текущей или указанной директории.

cd (Change Directory) — изменяет текущую рабочую директорию.

mkdir (make directory) — создаёт новый каталог.

touch — создаёт пустой файл или обновляет временные метки существующего файла.

rm (remove) — удаляет файлы или каталоги.

cp (copy) — копирует файлы и директории из одного места в другое.

cat — читает содержимое одного или нескольких файлов и выводит его в стандартный вывод (обычно в терминал).

3. Перечислите команды вывода основной информации системы.

uname -a — выводит полную информацию о системе, включая имя хоста, версию ядра, архитектуру процессора и другие данные.

uname -r — отображает версию ядра Linux.

lscpu — выводит общий обзор архитектуры центрального процессора.

lshw — предоставляет общий обзор аппаратного обеспечения системы.

lsblk — отображает информацию о блочных устройствах (дисках, разделах).

lsmod — получает список всех загруженных модулей ядра.

4. Перечислите команды ввода/вывода файлов.

cat — выводит содержимое одного или нескольких файлов в стандартный вывод (обычно в терминал). Если не указывать файлы, команда принимает ввод из STDIN.

echo — выводит текст или значения переменных в консоль. Без аргументов выводит пустую строку.

ls — отображает список файлов и директорий в текущей директории.

less — постраничный просмотр содержимого текстового файла. 

5. Возможно ли полноценное управление системой, пользуясь только командной строкой? Ответ обоснуйте.

Да, возможно (особенно в серверных ОС). Почти любое действие в GUI — это лишь "обертка" над системной командой. Через терминал можно управлять процессами, правами доступа, сетью и реестром быстрее и точнее, чем мышкой.

6. Подумайте, чем отличается командная строка Windows от командной строки MS-DOS, несмотря на их схожесть в командах.

MS-DOS была самостоятельной операционной системой, которая управляла ресурсами ПК напрямую. Командная строка Windows (CMD) — это эмулятор (приложение), запущенный внутри графической среды Windows. В CMD доступны многозадачность и длинные имена файлов, чего не было в классическом DOS.
